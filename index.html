Welcome to the course

Work through the tutorials in sequence. Each practical notebook opens directly in Google Colab, where you can run the code and upload your own CSV dataset. The notebooks include a small fallback example so you can practise before selecting a dataset.

Responsible practice: Use public, synthetic, or institution-approved datasets only. Never upload confidential logs, credentials, personal data, or live malware samples to Colab.

How to use the labs

1. Choose a tutorial below.
2. Select Open in Google Colab.
3. Run cells from top to bottom.
4. Upload your own CSV when prompted and complete the student tasks.
5. Save your Colab work to your Google Drive.
